# v0.12.0 引擎扩展决策

状态：开发候选，实现及冒烟进行中；人工验收前不运行完整回归。此前 v0.11.0 的测试结论不适用于本轮代码。

## 已确认的取舍

1. **结论：高档对经审核的纯缓存取消年龄限制。**
   **理由：** 退出应用后刚生成的可重建缓存也应能被清理；仅由精确模板白名单授予 AgePolicy，不以“Cache”名称或分组自动判断。临时文件、包／构建缓存、诊断资料及显卡着色器维持各自保留期。0 小时不绕过应用关闭、占用、只读、路径及身份复核。
2. **结论：系统维护是独立高级操作。**
   **理由：** 普通文件清理不应取得管理员权限。首轮只支持系统 DISM 的 /Online /Cleanup-Image /StartComponentCleanup，不含 /ResetBase；说明影响并确认后才请求 UAC。直接启动系统 DISM，不提升本工具、脚本或任务文件，不支持任意命令参数。无法事前精确统计释放量，不强杀、不自动重试。
3. **结论：只读发现与清理授权分离。**
   **理由：** 配置中的路径不构成删除许可。首轮识别 NuGet HTTP、pip 的明确覆盖配置及受支持布局，经用户确认精确缓存根后才纳入。来源值、目录身份或策略变化需重新确认；Worker 独立重新发现验证，只接受规则 ID，不接受 Root。
4. **结论：先减少可证实的误跳过，未知归属继续保守处理。**
   **理由：** 任意 WebView2 宿主不应必然阻止 Teams 缓存清理，但进程存在／不存在、文件未占用都不是独立安全证明。首轮优先细化 Teams 归属，npm／Python／Java 宿主不能证明无关时保留原守卫，不宣称全面解决。
5. **结论：独立实现，不直接搬用许可不兼容材料。**
   **理由：** BleachBit 所查代码／规则为 GPL-3.0-or-later；Winapp2 规则为 CC BY-SA 4.0；BCUninstaller 所查自有代码为 Apache-2.0，另有 NOTICE 和第三方例外。当前产品保留限制源码条款，不批量复制、翻译或收编规则；学习设计并另行核对官方布局，不改变 LICENSE。
6. **结论：编写与冒烟后先交人工验收。**
   **理由：** 用户指定交付顺序。不执行真实缓存删除、真实回收站清空、UAC 或 DISM；本轮不跑完整 Release、性能矩阵。源码检查和合成人工冒烟不等于真实应用重建或系统维护认证。

## 本轮边界

- 保持已获人工认可的弹窗前端，只在高级窗口加入必要入口。
- 版本为 v0.12.0 开发候选，独立构建目录，保留 v0.11.0 产物。
- 不自动提交、不修改 main、不更新正式 LATEST、不上传代码或配置。
- Delivery Optimization、便携浏览器／Firefox 自定义 Profile 映射等证据不足的项目不凑入支持清单。

## 用户验收后的待办

按最终策略迁移完整回归用例，专项核验授权变更、目录替换、进程归属、提权拒绝、DISM 退出状态、不同权限和位数；再决定正式发布。
