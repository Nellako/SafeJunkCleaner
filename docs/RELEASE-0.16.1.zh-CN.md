# v0.16.1 说明：大记录分析、选盘与推送前可靠性修订

本版产品版本维持 **0.16.1**（随新构建 `BuildId` 交付，保留旧历史包不覆盖）。版本号本身不代表正式发布或完整验收已经完成；实际构建指纹、校验哈希与已测／未测边界以随附清单及独立验证报告为准。

## 本版面向使用者的主要行为与修订

1. **快速选盘回填与取消行为**
   - 快捷盘符下拉框初始已显示 `C:` 等盘符时，再次确认同一项也会将 `C:\` 写入上方路径框，不必先切到别的盘再切回。
   - 按 `Escape` 取消菜单时保留手填或原有路径输入；选盘本身不会自动启动扫描。
2. **大范围盘点 Partial 说明与有界资源预算**
   - 盘点结果为 `Partial`（部分完成）时，界面会明确展示未覆盖对象数，并按链接／云占位、保护位置、元数据不可读、目录不可读等安全分类统计原因，不再只笼统报一个通用代码。未覆盖项不会进入可清理候选，已覆盖并可核验的分支仍可继续分析。
   - 分析阶段的托管内存判断不再固定为约 1GiB 上限，改为按本机物理安装内存的 1/8、当时空闲物理内存的 1/2 与 4GiB 三者较小值核定单次阶段的有界预算；低内存／低余量机器仍会保守停止，不承诺峰值内存或无限资源。
   - 内存不足时保留既有扫描记录，不再笼统引导重跑全盘盘点，用户可直接选择较小目录继续分析；保存问题报告时记录脱敏的安全原因码，不写入本机路径、文件正文或账号信息。
3. **“记录与帮助”页说明**
   - 界面中的空间数字（例如 `1GB / 5GB`）表示本程序为查看与分析保存的本地扫描索引占用及当前会话允许上限，**不是发现了垃圾，也不是即将删除的文件大小**。
   - 会话记录空间预算可在 `512–16384 MiB` 之间调节（默认 `512 MiB`，重开探索服务恢复默认），另有磁盘余量保护。
   - “整理扫描记录占用”仅整理程序自身数据库并保留占用空间的私有备份；“重置已结束的分析”只使旧建议与复核失效而不删除磁盘文件；“整理未确认清单”仅将失效未确认草稿移入保留区（仍占磁盘空间）。
4. **可靠性与交互闭环修订（v0.16.1 推送前修复范围）**
   - **执行状态完整性**：修正执行在部分写入或崩溃中断后的状态汇总语义，避免将未完成全部批准项或已消耗执行权但尚无账本的记录误报为“已完成”或“尚未开始”。
   - **后台复核准备取消**：在点击“生成复核清单…”尚未返回准备标识前点击“返回修改”，补齐后台取消衔接，避免旧准备任务滞留阻塞后续准备。
   - **最小窗口复核列表可读性**：保证在窗口允许的最小尺寸（`820×560`）下，复核文件列表仍保留可读行高，不因布局挤压导致无法核对精确文件后再批准。
   - **高级自定义 Escape 取消**：修正快速清理“高级自定义…”在未修改规则时按 `Escape` 取消触发属性缺失提示的问题，保持取消后原范围与扫描不变。
   - **旧库存升级配额恢复**：在保留物理空间配额保护与原有观测记录的前提下，为旧版索引在升级建索引阶段触及配额限制时提供可恢复入口，不再直接卡死在启动阶段。
    - **捆绑运行时与随包文档对齐**：自包含运行时与宿主包固定为 `.NET 10.0.15`，精确文件以组件清单与锁定还原记录为准；补齐许可正文、使用手册和安全／规则／开发说明，统一候选与正式包文件集合。

> 注：以上第 4 项中的代码与打包修复依赖对应代码提交与新构建的独立复测结果；在未取得新 `BuildId` 的全量独立验证结论前，不将历史断言数或旧测试报告直接视作本轮已通过证明。

## 安装、启动与核心边界

- 将完整 Windows ZIP 解压到普通本地目录，关闭旧版程序后再运行 `星梦雨垃圾清理器_v0.16.1.exe`。
- **必须保留同级 `星梦雨垃圾清理器_v0.16.1.exe.config` 与 `explorer/` 目录**，不要只复制单个 EXE 或混用不同版本的组件；本版不携带 `model/`。
- **不以目录名或文件大小判断可删**；深度探索建议默认不勾选，精确文件集合须经复核并两步确认批准，且**仅尝试移入回收站**（不提供永久删除）。
- 开发构建与候选包未签名，请勿关闭系统安全防护。
- 真实用户缓存清理、真实非空回收站清空、真实 UAC／DISM 系统维护及完整多 DPI／多显示器矩阵未在自动测试中实跑。
