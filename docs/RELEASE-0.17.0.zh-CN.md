# v0.17.0-beta.1：独立 QuickClean 后端与桌面启动修复

本版为 **0.17.0-beta.1 预发布**，不替换稳定版 `v0.16.1`。具体构建指纹（`BuildId`）、校验哈希和实际测试结果以本次发布随附清单为准。桌面启动所需的 C# 辅助代码已改为打包时编译，避免运行时因系统临时目录无法创建编译源文件而退出。

## 本轮主要架构与行为变化

1. **保留原 PowerShell／WPF 桌面界面**
   - 主窗口三档快速清理、明细与保留例外、高级自定义、只读环境缓存发现、DISM 系统维护与独立深度探索工作台均保持原有 PowerShell／WPF 界面与交互流程。
2. **独立 `.NET 10` 快速清理后端 `sjc-quickclean.exe`**
   - 将快速清理的扫描、分页预览／按规则查询、CSV 导出、只读历史记录查询、清理与清空回收站执行以及 DISM 签名／编录前置校验，迁移到独立 `.NET 10` 可执行文件 `sjc-quickclean.exe`。
   - 旧版 PowerShell 直接 Worker 执行路径不再作为生产清理入口（仅保留隔离自检 `SelfTest` 入口）。
3. **与 `sjc-explorer.exe` 共享自包含运行时**
   - `sjc-quickclean.exe` 与无模型深度探索宿主 `sjc-explorer.exe` 一同位于同级 `explorer/` 目录中，共享同一套自包含（self-contained）`.NET 10` 运行时与基础组件，用户无需单独安装 .NET SDK 或下载模型。
   - 本版延续无模型路线，不携带 `model/` 目录，也不启动任何 LLM 或 Python 组件。
4. **清理计划不继承旧执行权**
   - 快速清理的封存计划（`QuickClean/1`）绑定当前版本、任务属主、环境范围指纹、清理档位、规则集合与授权状态。
   - 历史版本（如 `v0.16.1` 及更早版本）留存的扫描计划、未执行草案或旧批准记录**不继承旧执行权**，不可直接在本版执行清理；跨版本使用或变更档位、规则、授权后，必须重新扫描并经用户确认后方可处理。
    - 深度探索的复核批准与快速清理的执行权各自独立，互不继承或跨流程复用。

本候选有两项使用差异：快速清理历史页重读的是本版已认证的任务记录，旧版没有同格式历史的任务不会自动导入；如果系统中有 WebView2 进程，本版 QuickClean 对 Teams 规则采用保守跳过，不承诺像旧实现那样区分所有无关宿主。两种情况均不会扩大可清理范围。

## 保留的已有核心功能

- **三档快速清理（主界面）**：
  - 支持低／中／高三档预设即时切换（高档零保留期仅限经模板审核的精确纯缓存白名单，仍不绕过进程、占用、只读、链接、未来时间与文件身份复核）。
  - 支持“高级自定义…”草稿编辑（默认关闭且重启不自动启用）、“发现缓存位置…”（仅只读检测 `NUGET_HTTP_CACHE_PATH` 与 `PIP_CACHE_DIR` 并经用户确认写入 DPAPI 授权）与“系统维护…”（经用户显式确认后仅调用系统自带 DISM `/Online /Cleanup-Image /StartComponentCleanup`，不含 `/ResetBase`）。
  - 支持查看分页文件明细、设置保留例外与导出完整 CSV；默认尝试移入回收站，永久删除与清空回收站均需单独确认。
- **无模型深度探索（独立工作台）**：
  - 支持单目录、单盘与逐盘串行固定磁盘批次的只读盘点，`Partial` 未覆盖项按安全原因分类计数且绝不进入候选。
  - 保留单次有界分析内存预算、会话内可调的 `512–16384 MiB` 扫描记录预算、磁盘余量保护、后台生成复核清单及仅提供移入回收站的两步确认机制。

## 安装、启动与包完整性要求

1. 将对应 `BuildId` 的完整 Windows 程序包解压到**普通本地目录**，关闭旧版正在运行的程序。
2. 运行用户入口：

```text
星梦雨垃圾清理器_v0.17.0.exe
```

3. **同级必需文件与目录（缺一不可）**：
   - `星梦雨垃圾清理器_v0.17.0.exe.config`：用于打包主程序启用长路径兼容。
   - `explorer/` 目录：包含共享自包含 `.NET 10` 运行时的 `sjc-quickclean.exe`、`sjc-explorer.exe` 及运行时／SQLite／许可声明组件。
   - 随包公开文档与许可文件（`README.md`、`LICENSE`、`THIRD-PARTY-NOTICES.md`、`assets/third-party/PS2EXE-LICENSE.txt`、`docs/` 下随包文档）。
4. **禁止只复制单个 EXE，也禁止将不同版本（如 `v0.16.1` 与 `v0.17.0`）的 EXE、`.exe.config` 或 `explorer/` 目录混用。**
5. 本轮为未进行第三方代码签名的本地开发候选，请勿为运行程序而关闭系统安全防护。

## 测试范围、安全边界与未实测说明

- **测试结果**：本说明不书写未经本轮验证的测试通过数、性能提升或产物大小数字；当前版本的实际构建指纹、回归验证、桌面观察及限制项**以本次交付报告为准**。
- **核心安全边界**：不以目录名、扩展名、文件大小或年龄自动认定可清理；重解析点／符号链接、部分云盘占位、UNC、ADS、只读、占用或权限不足项保守跳过；移入回收站通常不会立即释放磁盘可用空间。
- **未在自动验证中实跑的范围**：真实用户缓存清理、真实非空回收站清空、真实 UAC／DISM 执行、完整多 DPI／多显示器矩阵以及大规模真实文件内容分析均不作为自动验收通过依据。
- **本地数据位置**：快速清理配置、日志与任务位于 `%LOCALAPPDATA%\SafeJunkCleaner\v3`，探索状态与批准记录位于 `%LOCALAPPDATA%\SafeJunkCleaner\explorer` 及同级受保护目录（日志含本机路径，对外提供前请自行检查）。
