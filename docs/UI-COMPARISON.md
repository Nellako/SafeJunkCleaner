# v2.2.1 与 v0.9.0 界面对照

对比日期：2026-11-03。依据：用户提供的两张 v0.9.0 标注截图、旧版脚本与当前基线代码。不是对旧版全部运行场景的实测认证；v0.10.0 的实际验收另行记录。

## 结论

沿用 v0.9.0 的蓝白页面结构、完整候选和后台处理能力，恢复 v2.2.1 的紧凑分组与清晰列布局。不整体回退旧版，也不迁移为新的网页壳。

| 维度 | v2.2.1 | v0.9.0 基线 | 判断与改进 |
|---|---|---|---|
| 主列表 | WinForms 分类汇总，行高26，三列 | WPF工作台分类概览，另有完整逐文件候选页 | 两者主列表数据粒度不同，不能直接用行数判定功能优劣 |
| 文件详情 | 单独只读窗口；预览明细共享400条上限 | 完整分页，每页200条，保留排除和完整CSV | 保留当前完整性，改为紧凑表格，不恢复预览截断 |
| 候选布局 | 文件路径、大小、时间分列 | 路径换行、16/12内边距、状态与大小纵向叠放，无列标题 | 当前空间利用差；拆出文件名与目录，固定紧凑行，完整路径放详情 |
| 规则布局 | 带复选框的真实分组列表 | 每条多行卡片，重复显示路径、说明、风险、可用性 | 当前卡片过高；用紧凑分组列表与选中详情 |
| 分组操作 | 分组可见；快捷选择会替换选择范围 | 当前分组依据选中规则的Group，但无明确分组标题 | 批量操作必须显示实际作用组，不能依赖隐藏上下文 |
| 草稿和保留 | 旧选择行为不同 | 有应用／放弃草稿及规则级保留／恢复 | 保留有效机制，恢复改称取消保留，避免误认为恢复已删除文件 |
| 选择反馈 | 不同窗口承载详情 | 勾选状态跨页保留，但刷新详情只按当前页重建 | 统一全局选择计数和详情，明确浏览选中与批量勾选 |
| 视觉 | 更偏传统工具型 | 蓝白与侧栏一致，但留白和装饰牺牲密度 | 保留配色，不保留臃肿布局；实际WPF验收而非HTML演示 |
| 应用图标 | 内嵌旧立绘 | 自制蓝色几何图形 | 用户要求恢复旧立绘并加白底；用户已确认拥有相应权利 |

## 基线定位

- 旧脚本 `SafeJunkCleaner_v2.2.1.ps1`：988–998 行主汇总；1512–1536 行详情；1566–1621 行分组规则与快捷操作。
- v0.9.0 `src/Gui.ps1`：77–86 行候选及规则模板；152–188 行草稿与选择；190–235 行视图刷新。
- 上述行号用于基线追溯，后续代码变更后以函数和版本为准。

## 验收要求

- 在实际 WPF 窗口检查长路径、按钮不裁切、列表信息密度、规则搜索与分组、键盘可达性。
- 完整候选不能因布局修改而被截断；保留、取消保留、分页与CSV总数一致。
- 清理按钮及确认明确作用于全部未保留候选，不能误导为只处理当前勾选。
- 白底图标检查原图主体完整、各尺寸可辨识、窗口及EXE资源一致，不擅自清系统图标缓存。
- 对未运行的分辨率／DPI组合列为未测，不将静态模板检查称为视觉通过。

## v0.11.0 单界面调整（本地开发候选，实现中）

状态：实现与验收进行中，下表是目标设计，不是实测结论。正式稳定版 v0.10.0 仍为上文四页结构。

| 维度 | v0.10.0 | v0.11.0 目标 |
|---|---|---|
| 页面结构 | 工作台、候选、规则、记录四页 | 单界面完成选档、扫描、查看与清理 |
| 范围选择 | 规则页选推荐／深度，点击“应用范围”，可逐项勾选 | 低／中／高三档，选择即应用；普通使用无需逐项勾选 |
| 自定义 | 规则草稿可随时编辑 | 高级自定义默认关闭，重启后不自动启用；Explorer缓存只在此处提供 |
| 结果展示 | 紧凑逐文件候选表格 | 分类主表汇总，可展开分页明细 |
| 例外与导出 | 文件／规则保留、取消保留、完整CSV | 保留例外、取消保留与完整CSV继续提供 |

验收要求（追加）：

- 实际桌面窗口确认单界面流程、三档选择即应用及切换后要求重扫、高级自定义默认关闭且重启后仍关闭；对应发布脚本必需观察项 `SingleWindowFlowObserved`、`ThreePresetImmediateApplyObserved`、`AdvancedCustomOffByDefaultObserved`。
- 分类主表、展开明细、分页、保留例外与CSV总数一致，明细不因折叠而截断。
- 旧偏好迁移提示可见，且说明迁移为低档、旧文件保留。
- 选择高档时界面明确提示诊断资料不可重建。
- 记录见 [v0.11.0 验收记录](VALIDATION-0.11.0.md)；未执行的项目不得写为通过。
