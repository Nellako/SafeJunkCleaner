# 星梦雨垃圾清理器 · SafeJunkCleaner

**v0.9.0｜Windows 本地桌面清理工具**

通过内置规则扫描缓存与临时文件，先展示候选，再由用户确认处理。采用 WPF 界面、Windows PowerShell 5.1 引擎及独立后台进程；不需要服务器、账号或数据库，不上传文件。

> **APP 免费使用，源码公开供查看，但不授予源码使用、修改或再分发许可。本项目不是开源项目。** 详见 [LICENSE](LICENSE)。

## 功能

- 工作台、候选文件、清理规则、任务记录四页界面。
- 内置精确目录规则、受限浏览器多 Profile 发现、按规则保留时间。
- 完整候选分页、单文件及规则保留/恢复、完整 CSV 导出。
- 默认尝试移入回收站；永久删除与回收站清空独立确认。
- 清理前重新核对规则、路径、链接、大小、修改时间及文件身份。
- 后台扫描/清理和预览索引，支持取消、部分结果与本地日志。

## 使用

从维护者正式发布的 Release 获取应用包，解压后双击 `星梦雨垃圾清理器_v0.9.0.exe`。

1. 在“清理规则”检查范围并应用；推荐项也可以取消。
2. 点击“开始扫描”，扫描不删除文件。
3. 查看候选，保留不希望处理的文件。
4. 确认处理方式后清理；完成后重新扫描才知道当前剩余量。

**移入回收站通常不会立即释放对应磁盘空间。** “已处理逻辑大小”不是精确的磁盘可用空间变化。首次启动不会自动扫描或删除。

### 运行环境

- Windows 桌面环境、Windows PowerShell 5.1、相应 .NET Framework WPF 组件。
- 无需浏览器、Node.js 或 Python。不会自动提权、修改权限或结束其他应用。
- 未签名构建可能被系统提示；不要为了运行程序关闭安全防护。
- 当前版本不是对所有 Windows、DPI、应用版本和文件系统布局的兼容认证。

## 安全边界

清理规则不是“所有缓存都绝对可删”的保证。重要文件请先备份，并阅读 [安全说明](docs/SAFETY.md)。

- 不提供全盘扩展名删除、任意目录或其他账户清理。
- 不把数据库 WAL/SHM、Office 待同步缓存、Maven 混合仓库和网页离线数据作为通用垃圾。
- 文件变化、只读、权限不足、链接重定向或前置条件不满足时保守跳过。
- 保守拒绝部分云盘/重解析路径、UNC、ADS 和特殊路径；CSV 只导出到安全目录中的新文件。
- 同一用户权限的恶意程序与检查至删除的时序竞态，不是本工具能够完全隔离的边界。

## 本地数据

设置、日志和任务记录位于 `%LOCALAPPDATA%\SafeJunkCleaner\v3`。`v3` 是历史内部存储命名，不是当前对外版本；保留它避免误迁移既有设置。应用版本统一以 `version.json` 为准。

日志与候选包含完整本机路径，目录按当前用户和 SYSTEM 私有权限创建；本版不自动轮转所有日志或清除历史测试材料。对外提供日志前请自行检查。旧版本扫描计划不直接执行，必须重新扫描。
