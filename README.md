## 功能

- 单界面流程：选档、扫描、查看结果和清理在同一界面完成（v0.11.0 引入，v0.12.0 沿用）。
- 低／中／高三档预设替代原推荐／深度两档。选择档位即应用，普通使用无需逐项勾选规则；新用户默认中档。档位成员与最低保留时间见 [规则说明](docs/RULES.md)。
- **高档零保留期仅限精确纯缓存白名单**：Chrome／Edge／Brave 的 Cache、Code Cache、GPUCache，Firefox cache2，VS Code Cache／CachedData，新版 Teams 三个精确缓存及经典 Teams GPUCache。其他规则（Temp、包／构建缓存、诊断资料、显卡着色器等）仍为正数保留期。零保留期不绕过应用关闭、占用、只读、链接、未来时间和文件身份检查。
- 高级自定义默认关闭，重启后也不会自动启用。资源管理器图标／缩略图缓存不属于任何预设，只能在高级自定义中选择。该窗口新增“发现缓存位置…”和“系统维护…”两个入口。
- 内置精确目录规则、受限浏览器多 Profile 发现；预设纳入已有的 npm、NuGet HTTP、pip、Yarn Classic、Go、Gradle、经典 Teams、Firefox cache2 等限定缓存，以及新版 Teams 的三个固定缓存子目录。这不等于旧版 51 项已全部恢复，未支持项见规则说明。
- 新版 Teams 的 WebView2 宿主归属能明确判为无关时不再整类阻断；归属未知、父链变化或权限不足时保守跳过，不结束进程。npm／Python／Java 等共享宿主未细化，保留原守卫。
- 缓存位置发现（只读）：来源只有当前进程环境变量 `NUGET_HTTP_CACHE_PATH` 和 `PIP_CACHE_DIR`，不遍历任意配置文件，不接受用户输入任意路径，也不执行 Python 或 pip。发现不等于授权，须在界面确认；授权绑定展示时的来源、路径、目录身份和模板，变化后失效，可随时撤销。详见[安全说明](docs/SAFETY.md)。
- 系统维护是独立高级操作，唯一动作为系统 DISM 的 `/Online /Cleanup-Image /StartComponentCleanup`，不含 `/ResetBase`；说明并确认后才请求 UAC，文件清理器本身不提权。旧组件可能立即删除并影响更新回退，释放量无法事前精确统计。
- 结果按组在主表汇总；扫描完成后通过“查看文件明细”打开独立窗口，保留例外、取消保留和完整 CSV 导出继续提供。清理范围为当前档位下全部未保留候选。
- “高级自定义…”在弹窗中编辑草稿，确定才应用；取消或关闭不改变现有范围，未修改时确定也不使扫描失效。
- 默认尝试移入回收站；永久删除与回收站清空独立确认。
- 清理前重新核对规则、路径、链接、大小、修改时间及文件身份。
- 后台扫描/清理和预览索引，支持取消、部分结果与本地日志。

## 使用

从维护者提供的本地交付目录获取 Windows ZIP，对照 `SHA256SUMS` 校验后解压，运行 `星梦雨垃圾清理器_v0.12.0.exe`。完整源码 ZIP 与应用 ZIP 分开；源码构建命令见下文。父目录 `releases/README.md` 和 `LATEST.json` 指向成功通过最终门禁的成品；若仍指向旧版，说明 v0.12.0 尚未完成交付，不要把 `artifacts/builds` 中间构建当正式包。

v0.12.0 的使用流程：

1. 选择低／中／高档位，选择后立即生效。确有需要时才开启高级自定义调整规则。
2. 点击“开始扫描”，扫描不删除文件；切换档位或规则后，旧扫描结果失效，必须重扫。
3. 在分类主表查看各类别汇总，扫描完成后按需打开文件明细窗口，把不希望处理的文件或规则设为保留例外。勾选本身不限制清理范围，保留项才会被排除。
4. 核对确认窗口的实际对象、影响和处理方式后清理；完成后重新扫描才知道当前剩余量。

**高档包含崩溃转储和 WER 归档，删除后无法重建，会失去历史故障诊断资料。** 包缓存、构建缓存和浏览器缓存可以重建，但需要重新下载或编译。

**移入回收站通常不会立即释放对应磁盘空间。** “已处理逻辑大小”不是精确的磁盘可用空间变化。首次启动不会自动扫描或删除。

### 运行环境

- Windows 桌面环境、Windows PowerShell 5.1、相应 .NET Framework WPF 组件。
- 无需浏览器、Node.js 或 Python。文件清理不提权，也不会修改权限或结束其他应用。仅“系统维护…”在单独确认后，才为系统自带 DISM 请求一次 UAC，本工具自身不被提升。
- 未签名构建可能被系统提示；不要为了运行程序关闭安全防护。
- 当前版本不是对所有 Windows、DPI、应用版本和文件系统布局的兼容认证。

## 安全边界

清理规则不是“所有缓存都绝对可删”的保证。重要文件请先备份，并阅读 [安全说明](docs/SAFETY.md)。

- 不提供全盘扩展名删除、任意目录或其他账户清理。
- 不把数据库 WAL/SHM、Office 待同步缓存、Maven 混合仓库和网页离线数据作为通用垃圾。
- 文件变化、只读、权限不足、链接重定向或前置条件不满足时保守跳过。
- 配置或环境变量中出现的路径不构成删除许可；缓存位置须先发现、再由用户确认。Worker 只接受规则 ID，不接受任意 Root。
- 未验证边界：真实缓存删除、真实回收站清空、真实 UAC／DISM、完整多 DPI／多显示器矩阵均未验证；构建未签名。
- 保守拒绝部分云盘/重解析路径、UNC、ADS 和特殊路径；CSV 只导出到安全目录中的新文件。
- 同一用户权限的恶意程序与检查至删除的时序竞态，不是本工具能够完全隔离的边界。

## 本地数据

设置、日志和任务记录位于 `%LOCALAPPDATA%\SafeJunkCleaner\v3`。`v3` 是历史内部存储命名，不是当前对外版本；保留它避免误迁移既有设置。应用版本统一以 `version.json` 为准。

自 v0.11.0 起，偏好存为同目录下的 `preferences-v4.json`（v0.12.0 沿用）。没有偏好文件的新用户默认中档。若只存在旧版 `preferences-v3.json`，候选会将其迁移为低档预设，不启用高级自定义，也不沿用旧版的可选勾选，并显示迁移提示；旧文件原样保留，不删除、不改写。

缓存位置授权保存为同目录下由 Windows DPAPI 保护的 `cache-authorizations-v1.dpapi`。该文件和私有目录权限不是对同一用户下恶意程序的隔离边界，也不能授予管理员权限。可在“发现缓存位置…”中撤销授权。

日志与候选包含完整本机路径，目录按当前用户和 SYSTEM 私有权限创建；本版不自动轮转所有日志或清除历史测试材料。对外提供日志前请自行检查。旧版本扫描计划不直接执行，必须重新扫描。
