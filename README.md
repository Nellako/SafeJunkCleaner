# 星梦雨垃圾清理器 · SafeJunkCleaner

**v0.17.0-beta.1｜Windows 本地快速清理与深度探索（预发布）**

> 当前源码版本为 **0.17.0-beta.1**，不替换稳定版。Windows 文件版本仍为 `0.17.0.0`。产品使用方式、架构边界与限制见 [Beta 1 说明](docs/RELEASE-0.17.0.zh-CN.md) 与 [使用手册](docs/使用手册.md)；实际校验与测试结论以随附清单为准。

本项目提供两套相互独立的本地清理与分析流程：**三档快速清理**（固定精确缓存规则）与 **无模型深度探索**（只读盘点、结构探测与两步回收复核）。本版保留原有 PowerShell／WPF 桌面界面，并将快速清理执行后端迁移为独立 `.NET 10` 程序 `sjc-quickclean.exe`，与深度探索宿主 `sjc-explorer.exe` 一同位于 `explorer/` 目录并共享自包含运行时，配合本地 SQLite 索引运行；无需账号或联网，不上传本机文件，也不携带或启动 LLM、GGUF、llama.cpp 或 Python。

> **APP 免费使用，源码公开供查看，但不授予源码使用、修改或再分发许可。本项目不是开源项目。** 详见 [使用与源码查看条款](LICENSE)。

## 功能概览

### 1. 无模型深度探索（独立工作台）

- **先盘点，后调查**：只读扫描用户明确选定的文件夹、单个磁盘或逐盘串行的固定磁盘，在本地 SQLite 建立索引；盘点本身不修改或删除文件。
- **持续探索与有界资源**：不再因固定的 25 万条对象、128 个目标或 30 秒时限提前中止，改为按完成状态、用户取消与单次有界资源预算（按安装物理内存的 1/8、当时空闲内存的 1/2 与 4GiB 三者较小值核定，低余量仍保护）推进；默认会话记录空间预算为 `512 MiB`，可在 `512–16384 MiB` 之间按本次会话调整（重开恢复默认），另有磁盘余量保护。
- **结构证据与部分覆盖**：仅依据受支持缓存或构建输出的结构证据给出分级建议（如旧式块缓存、受限 `.NET bin/obj`、受限前端 `dist` 等；Simple Cache v5 试点与重复安装包、大文件仅作整理展示，不可进入回收）。优先级、名称、体积或年龄都不构成可删授权。遇到链接、云占位、权限受限或保护位置时记为未覆盖（`Partial`）并按安全分类计数，**部分覆盖不等于完整或安全**，未覆盖对象绝不进入候选。
- **后台复核与仅探索回收**：建议默认不勾选；“生成复核清单…”在后台核验精确文件集合并支持返回取消。**探索入口只提供移入回收站，不提供永久删除**；需先后完成“第一步：确认此清单”和“第二步：移入回收站…”，执行前逐项复查文件身份与策略，结果异常时可在只读分页记录中核对。

### 2. 三档快速清理（主界面）

- **低／中／高三档预设**：选择档位即应用（新用户默认中档），切换档位或规则后旧扫描结果失效须重扫。成员范围与保留时间见 [规则说明](docs/RULES.md)。
- **高档零保留期仅限精确纯缓存白名单**：仅覆盖经模板审核的 Chrome／Edge／Brave（Cache、Code Cache、GPUCache）、Firefox `cache2`、VS Code（Cache、CachedData）、新版 Teams 三个固定缓存子目录与经典 Teams `GPUCache`；Temp、包／构建缓存、崩溃转储／WER 归档与显卡着色器等仍为正数保留期，且不绕过进程、占用、只读、链接、未来时间与文件身份检查。
- **高级自定义与附加入口**：高级自定义默认关闭且重启不自动启用；“高级自定义…”在弹窗草稿中编辑，取消不改现有范围。另提供两个独立高级入口：
  - **发现缓存位置…（只读）**：仅读取当前进程环境变量 `NUGET_HTTP_CACHE_PATH` 与 `PIP_CACHE_DIR`，不遍历任意配置文件、不执行工具命令；发现不等于授权，须用户在界面核对并确认后生效，可随时撤销。
  - **系统维护…（独立提权入口）**：仅用于说明并确认后调用系统自带 DISM（`/Online /Cleanup-Image /StartComponentCleanup`，不含 `/ResetBase`），由 DISM 独立请求一次 UAC，本清理器自身不提权；取消不触发 UAC 或 DISM。
- **明细与保留例外**：主表按类别汇总，扫描过程显示已检查数、已发现候选数与用时；可在“查看文件明细”中设置保留例外或导出完整 CSV（保留例外才排除，仅勾选不限制范围）。默认尝试移入回收站，永久删除与清空回收站均需单独确认。
- **独立快速清理后端与计划不继承**：快速清理的扫描、分页预览／导出、历史查询、清理执行与 DISM 前置校验由独立 `.NET 10` 后端 `sjc-quickclean.exe` 承载，界面沿用原有 PowerShell／WPF 实现；旧版或先前版本的扫描／清理计划与批准记录**不继承旧执行权**（旧计划不可直接用于执行清理，版本、档位、规则或授权变更后须重新扫描并确认）。

## 安装与使用

获取对应 `BuildId` 的完整 Windows 程序包后，核对校验清单并解压到**普通本地目录**，关闭旧版后运行：

```text
星梦雨垃圾清理器_v0.17.0.exe
```

**包完整性要求（缺一不可）：**

- 主程序同级必须同时保留 `星梦雨垃圾清理器_v0.17.0.exe.config`（启用长路径兼容）与 `explorer/` 目录（内含共享 `.NET 10` 自包含运行时的独立后端 `sjc-quickclean.exe` 与探索宿主 `sjc-explorer.exe`，无需用户另装 .NET SDK 或下载模型）；本版不含 `model/` 目录。
- 不要只复制单个 EXE，也不要把不同版本的 EXE、`.exe.config` 或 `explorer/` 混用。
- 本轮为本地开发候选，未进行第三方代码签名；不要为了运行程序而关闭系统安全防护。

### 快速上手提示

- **快速清理**：选低／中／高档位 → 点击“开始扫描” → 按需打开文件明细设置保留例外 → 核对确认窗口的对象与处理方式后执行；完成后或跨版本升级后需重新扫描（清理计划不继承旧执行权）。
- **深度探索**：打开“深度探索…” → 通过路径框或“快速选盘”选定目录或磁盘（点击“开始探索”才启动） → 在“建议与处理”按需分析当前任务 → 仅勾选确认要处理的“可进入复核”组并生成复核清单 → 分两步确认并移入回收站。
- **记录与帮助页**：界面显示的记录占用（如已用量 / 会话上限）是本程序在本地保存的扫描记录索引空间，**不是待清理垃圾量，也不是即将删除的文件大小**；遇到异常可点击保存脱敏问题报告。详情见 [使用手册](docs/使用手册.md)。

### 运行环境

- Windows 桌面环境、Windows PowerShell 5.1、系统自带 .NET Framework WPF 组件（承载原 PowerShell／WPF 桌面界面），以及随包携带的 `explorer/` 自包含 `.NET 10` 运行时（由 `sjc-quickclean.exe` 与 `sjc-explorer.exe` 共享；精确运行时版本与校验值以包内组件清单及本次交付报告为准）。
- 文件清理不提权、不修改系统权限、不强制结束其他应用。仅“系统维护…”在用户显式确认后才为系统 DISM 请求一次 UAC。
- 当前本地开发候选不是对所有 Windows 版本、DPI 缩放、多显示器组合或第三方应用布局的兼容认证。

## 安全边界与未实测范围

请在使用前阅读 [安全说明](docs/SAFETY.md)。

- 不以目录名、扩展名、文件大小或年龄自动认定可清理；精确候选集合须由用户复核批准。
- 不支持全盘按扩展名删除、任意目录盲删、其他账户清理，也不把数据库 WAL/SHM、Office 待同步缓存、Maven 混合仓库或网页离线存储作为通用垃圾。
- 重解析点／符号链接、部分云盘占位、UNC、ADS、只读、占用或权限不足项保守跳过；检查至执行之间的极短时序竞态及同用户权限恶意程序不是本工具可完全隔离的边界。
- **未在自动验证中实跑的范围**：真实用户缓存清理、真实非空回收站清空、真实 UAC／DISM 系统维护、完整多 DPI／多显示器矩阵，以及大规模真实文件内容分析均未作为自动验收通过依据；本轮具体已测与未测结果以本次交付报告为准。
- **本地数据位置**：设置、日志与快速清理任务位于 `%LOCALAPPDATA%\SafeJunkCleaner\v3`（`v3` 为内部兼容路径名，不代表对外版本；应用版本以 `version.json` 为准），偏好存为 `preferences-v4.json`，缓存授权存为受 DPAPI 保护的 `cache-authorizations-v1.dpapi`，旧版清理计划不继承旧执行权；探索状态与批准记录位于 `%LOCALAPPDATA%\SafeJunkCleaner\explorer` 及同级受保护目录。本地日志与任务索引含本机路径，对外提供前请自行检查。
